## 🟢 [v1.0.0] — *Released (Aug 1, 2026)*

> **Focus**: Core AI-Era Engine & High-Performance SkiaSharp Vector Pipeline

### Core Release Features
- 🤖 **Universal Markdown Ingestion Engine**: Native parsing of LLM response markdown strings into PDF layout AST.
- 📐 **Anti-Orphan Auto-Fit Engine**: Dynamic micro-scaling algorithm eliminating 1.05-page orphan spills onto blank second pages.
- 🧠 **AI / RAG Dual-Stream Metadata**: Loss-free JSON AST embedded directly inside PDF binary metadata for instant vector database indexing.
- 🎨 **Preset Design Systems**: Out-of-the-box production themes (`SaaSAnalytics`, `ExecutiveMinimal`, `GlassmorphicDark`).
- 🛡️ **Cryptographic Licensing Engine**: RSA/HMAC-SHA256 signature validation with tier permissions.
- ⚡ **SkiaSharp Vector Core**: Resolution-independent vector PDF compilation ($15\text{ ms}$ render latency).
