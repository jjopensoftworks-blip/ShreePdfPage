Why .NET 8 and .NET 10 engineering teams are migrating from verbose QuestPDF lambda trees to ShreePdf's Markdown-native, theme-driven native vector engine.

Code Comparison: Nested Lambdas vs. Fluent & Markdown

Stop debugging deeply nested container.Page(page => page.Content().Column(col => ...)) trees.

QuestPDF (35+ Lines of Nested Lambdas) High Boilerplate
Document.Create(container => { container.Page(page => { page.Size(PageSizes.A4); page.Margin(2, Unit.Centimetre); page.Header().Text("Quarterly SaaS Report").SemiBold().FontSize(20); page.Content().PaddingVertical(1, Unit.Centimetre).Column(col => { col.Spacing(10); col.Item().Text("Revenue grew 24% YoY across enterprise tiers."); col.Item().Table(table => { table.ColumnsDefinition(cols => { cols.RelativeColumn(3); cols.RelativeColumn(1); }); table.Header(h => { h.Cell().Text("Segment").Bold(); h.Cell().AlignRight().Text("ARR").Bold(); }); table.Cell().Text("Enterprise"); table.Cell().AlignRight().Text("$1,240,000"); }); }); page.Footer().AlignCenter().Text(x => { x.CurrentPageNumber(); x.Span(" / "); x.TotalPages(); }); }); }).GeneratePdf("report.pdf");
ShreePdf (10 Lines + Preset Design System) 75% Less Code
using ShreePdf.Fluent; Document.Create("Quarterly SaaS Report") .WithTheme(ThemePresets.SaaSAnalytics) .AddHeading("Quarterly SaaS Report", level: 1) .AddText("Revenue grew 24% YoY across enterprise tiers.") .AddTable(t => { t.Columns.Add(new TableColumn { Header = "Segment", WidthRatio = 3 }); t.Columns.Add(new TableColumn { Header = "ARR", WidthRatio = 1, Alignment = Alignment.Right }); t.Rows.Add(new TableRow { Cells = { "Enterprise", "$1,240,000" } }); }) .AddPageNumber("Page {page} of {pages}") .EnableAutoFit() .Save("report.pdf");

Built for AI & LLM Pipelines (Markdown → Vector PDF)

When building with Microsoft.Extensions.AI or Semantic Kernel, LLMs return Markdown. With QuestPDF you have to write your own Markdown parser. With ShreePdf, it is one line of code:

Direct LLM Markdown + Native Vector Charts Zero External Parsers
using ShreePdf.Fluent; Document.FromMarkdown(llmMarkdownResponse, ThemePresets.ExecutiveMinimal) .AddStatCards( new StatCard("Net Retention", "118%", "+6.2% YoY", deltaPositive: true), new StatCard("Gross Margin", "84.5%", "+2.1% YoY", deltaPositive: true)) .AddBarChart("Quarterly ARR ($K)", ("Q1", 820), ("Q2", 950), ("Q3", 1100), ("Q4", 1240)) .EnableAutoFit() .Save("ai-executive-briefing.pdf");
